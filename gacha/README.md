# 群友图鉴

她给群里的每个人画一张收藏卡，大家每天抽一张、慢慢集齐，还能互相送、互相换、升星。卡面的称号、技能和批注是人格自己写的，属性来自真实聊天数据；群里的名场面会被做成引用原话的限量 UR 卡，三星卡能觉醒成她专门画了插画的 SSR 超级卡。回复用她自己的口气（她每周写一本台词本）。卡面由 Pillow 在本地绘制，插画走框架的插件生图入口。

[权威文档](https://sirius-pulse-docs.vercel.app/extensions/gacha)

## 启用

1. 使用 Sirius Pulse **1.3.0+**，确保 `plugins/` 子模块已初始化且包含本目录。
2. 插件默认启用，不想要可以在 WebUI 的插件管理里关掉「**群友图鉴**」。所有群成员都能玩，私聊里不能玩。
   只有在有人 `/抽卡` 过的群里，她才会在后台给群友画卡。
3. 写卡和说话走 `plugin_generate` 任务（宿主注入完整人设），插画走 `image_generate` 任务，请确认两者在 AMKR 里都绑定了模型。

## 指令

| 指令 | 行为 |
| --- | --- |
| `/抽卡` | 抽一张本群的卡，每人每天 `draws_per_day` 次（默认 1）；抽到 SR 以上她会亲口说一句 |
| `/图鉴` | 本群的收集进度，没抽到的是问号 |
| `/卡 <名字或编号>` | 看一张已经抽到的卡 |
| `/送卡 <人> <编号>` | 把一份卡送给群友（名字或 @） |
| `/交换 <人> <我的编号> <他的编号>` | 提出换卡；对方 10 分钟内 `/同意交换` 或 `/拒绝交换` |
| `/升星 <编号>` | 用一份重复的卡升星（最多 3 星），解锁她写给你的一句悄悄话 |
| `/觉醒 <编号>` | 三星卡觉醒成 SSR 超级卡，她专门画一张插画，画好在群里叫你 |
| `/我的卡` | 看她给你画的卡 |
| `/我的卡 退出` / `/我的卡 加入` | 退出图鉴（画了你的卡和你出演的名场面都从所有人手里删掉、不再画）/ 回来 |

## 四种卡

- **R 常驻卡**：每个在群里说话够多的人一张。
- **SR 心情卡**：她心情好时给已有卡的人随手再画一张；每群每天最多一张，同一人 30 天最多一张。心情好时 SR 以上出率 ×1.2。
- **SSR 觉醒卡**：三星卡 `/觉醒`，她换称号和技能、专门画一张插画，只此一份，不能送也不能换。
- **UR 名场面卡**：近一天里最热闹的十分钟，她觉得值得就做成引用原话的卡并配插画，限量 `moment_supply` 份，每群每周最多一张。

插画里不出现真实的人，群友只用象征物表示；她自己按 `{persona}/assets/` 里的形象图出现。

## 设置

| 键 | 默认 | 作用 |
| --- | --- | --- |
| `draws_per_day` | 1 | 每人每天在每个群能抽几次 |
| `min_messages` | 20 | 在群里至少说过多少句话才会被画 |
| `cards_per_beat` | 2 | 后台每次（约 10 分钟）最多新画几张 |
| `cards_per_day` | 20 | 整个人格每天最多新画几张（常驻卡、心情卡、名场面合计；觉醒用插画额度） |
| `moment_supply` | 3 | 每张名场面卡一共能被抽出几份 |
| `art_per_day` | 3 | 每天最多画几张插画（觉醒与名场面合计）；0 表示不画、不能觉醒 |

## 隐私

卡池按群隔离；写卡面的材料只有这个人在本群的公开发言，名场面只取本群那十分钟里的原话，私聊和别的群的话不会进去。本人发 `/我的卡 退出` 即删除画了自己的所有卡。数据保存在 `{persona}/artifacts/gacha/`。
