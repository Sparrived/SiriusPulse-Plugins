# 群友图鉴

她给群里的每个人画一张收藏卡，大家每天抽一张、慢慢集齐。卡面的称号、技能和批注是人格自己写的，属性来自真实聊天数据；卡面图由 Pillow 在本地绘制，抽卡本身不调用模型。

[权威文档](https://sirius-pulse-docs.vercel.app/extensions/gacha)

## 启用

1. 使用 Sirius Pulse **1.3.0+**，确保 `plugins/` 子模块已初始化且包含本目录。
2. 插件默认启用，不想要可以在 WebUI 的插件管理里关掉「**群友图鉴**」。所有群成员都能玩，私聊里不能玩。
   只有在有人 `/抽卡` 过的群里，她才会在后台给群友画卡。
3. 画卡走 `plugin_generate` 任务（带人设），请确认它在 AMKR 里绑定了模型。

## 指令

| 指令 | 行为 |
| --- | --- |
| `/抽卡` | 抽一张本群群友的卡，每人每天 `draws_per_day` 次（默认 1） |
| `/图鉴` | 本群的收集进度，没抽到的是问号 |
| `/卡 <名字或编号>` | 看一张已经抽到的卡 |
| `/我的卡` | 看她给你画的卡 |
| `/我的卡 退出` / `/我的卡 加入` | 退出图鉴（卡从所有人手里删掉、不再画）/ 回来 |

## 设置

| 键 | 默认 | 作用 |
| --- | --- | --- |
| `draws_per_day` | 1 | 每人每天在每个群能抽几次 |
| `min_messages` | 20 | 在群里至少说过多少句话才会被画 |
| `cards_per_beat` | 2 | 后台每次（约 10 分钟）最多新画几张 |
| `cards_per_day` | 20 | 整个人格每天最多新画几张 |

## 隐私

卡池按群隔离；写卡面的材料只有这个人在本群的公开发言，私聊和别的群的话不会进去。本人发 `/我的卡 退出` 即删除自己的卡。数据保存在 `{persona}/artifacts/gacha/`。
