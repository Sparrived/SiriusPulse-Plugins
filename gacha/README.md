# 群友图鉴

她给群里的每个人画一张收藏卡，大家每天抽一张、慢慢集齐，还能互相送、互相换、升星。卡面的称号、技能和批注是人格自己写的，属性来自真实聊天数据；群里的名场面会被做成引用原话的限量 UR 卡，三星卡能觉醒成她专门画了插画的 SSR 超级卡。每一句回复都是她现场说的（带完整人设、她此刻的心情和她最近说过的话），指令用法、刷新时间这类规则漏了由系统补上；开不了口时用她每周写的台词本兜底。卡面由 Pillow 在本地绘制，插画走框架的插件生图入口。

[权威文档](https://sirius-pulse-docs.vercel.app/extensions/gacha)

## 启用

1. 使用 Sirius Pulse **1.3.0+**，确保 `plugins/` 子模块已初始化且包含本目录。
2. 插件默认启用，不想要可以在 WebUI 的插件管理里关掉「**群友图鉴**」。所有群成员都能玩，私聊里不能玩。
   只有在有人 `/抽卡` 过的群里，她才会在后台给群友画卡。
3. 写卡和说话走 `plugin_generate` 任务（宿主注入完整人设），插画走 `image_generate` 任务，请确认两者在 AMKR 里都绑定了模型。

## 指令

| 指令 | 行为 |
| --- | --- |
| `/抽卡` | 抽一张本群的卡，每次刷新后每人 `draws_per_day` 次（默认 1）；抽完她会亲口说一句 |
| `/抽卡 帮助` | 她说一句，附上一张玩法卡（全部指令 + 本群每轮几抽、几点刷新、保底） |
| `/抽卡 刷新时间` | 看本群几点刷新；**root** 可以 `/抽卡 刷新时间 08:00 20:00` 给本群另设、`/抽卡 刷新时间 默认` 恢复 |
| `/抽卡 刷新` | **仅 root**：马上刷新本群的抽卡次数（同一天可多次） |
| `/图鉴` | 本群的收集进度，没抽到的是问号 |
| `/卡 <名字或编号>` | 看一张已经抽到的卡 |
| `/送卡 <人> <编号>` | 把一份卡送给群友（名字或 @） |
| `/交换 <人> <我的编号> <他的编号>` | 提出换卡；对方 10 分钟内 `/同意交换` 或 `/拒绝交换` |
| `/升星 <编号>` | 用一份重复的卡升星（最多 3 星），解锁她写给你的一句悄悄话 |
| `/觉醒 <编号>` | 三星卡觉醒成 SSR 超级卡，她专门画一张插画，画好在群里叫你 |
| `/我的卡` | 看她给你画的卡 |
| `/我的卡 退出` / `/我的卡 加入` | 退出图鉴（画了你的卡和你出演的名场面都从所有人手里删掉、不再画，「画我」也撤回）/ 回来 |
| `/我的卡 画我` / `/我的卡 不画我` | 同意她画你的觉醒插画时照你本人登记的形象画你 / 撤回（已经照你画好的插画立刻撤下） |

## 四种卡

- **R 常驻卡**：每个在群里说话够多的人一张。
- **SR 心情卡**：她心情好时给已有卡的人随手再画一张；每群每天最多一张，同一人 30 天最多一张。心情好时 SR 以上出率 ×1.2。
- **SSR 觉醒卡**：三星卡 `/觉醒`，她换称号和技能、专门画一张插画，只此一份，不能送也不能换。
- **UR 名场面卡**：近一天里最热闹的十分钟，她觉得值得就做成引用原话的卡并配插画，限量 `moment_supply` 份，每群每周最多一张。

插画里默认不出现真实的人，群友只用象征物表示；她自己按 `{persona}/assets/` 里的形象图出现。

## 画我

卡上的人自己发 `/我的卡 画我`，并且在框架的视觉资产系统里登记了已启用的正式形象，他那张卡觉醒时插画就照他本人的样子画；名场面卡始终只用象征物。

- 同意用他这条消息的来源证据记成视觉资产授权（只限这个群、只限生图、留审计），插件自己不碰任何人的照片；
- 画的时候走 `EngineProxy.generate_person_image()`：授权、部署方人物生图额度、预检、结果隔离都由框架负责；
- 没同意、没登记、额度用完……就照旧用象征物画，不是本人选择的原因会在群里如实说一句；
- `/我的卡 不画我` 或 `退出`：撤回授权，正在画的取消或隔离，已经照他画好的插画文件删掉、从卡上撤下（卡保留）。

## 刷新

root 是 NapCat 适配器配置里的 `root`（主人的 QQ 号），只比对发送者账号。插件记的是每个人上次真正抽卡的时刻，改刷新时间不会白送一轮，只有在那之后真的过了一个刷新时刻或手动刷新，次数才回来。

## 设置

| 键 | 默认 | 作用 |
| --- | --- | --- |
| `draws_per_day` | 1 | 每次刷新后，每人在每个群能抽几次 |
| `refresh_times` | `00:00` | 每天几点刷新（中国时间），可以写好几个，如 `00:00, 12:00, 20:00` |
| `min_messages` | 20 | 在群里至少说过多少句话才会被画 |
| `cards_per_beat` | 2 | 后台每次（约 10 分钟）最多新画几张 |
| `cards_per_day` | 20 | 整个人格每天最多新画几张（常驻卡、心情卡、名场面合计；觉醒用插画额度） |
| `moment_supply` | 3 | 每张名场面卡一共能被抽出几份 |
| `art_per_day` | 3 | 每天最多画几张插画（觉醒与名场面合计）；0 表示不画、不能觉醒 |
| `live_voice` | 开 | 每句回复都由她现场说（每条指令一次模型调用）；关掉只用台词本和保底句 |

## 隐私

卡池按群隔离；写卡面的材料只有这个人在本群的公开发言，名场面只取本群那十分钟里的原话，私聊和别的群的话不会进去。本人发 `/我的卡 退出` 即删除画了自己的所有卡和插画文件；插画里出现真实的人只限本人 `/我的卡 画我` 同意的那位，随时可以 `/我的卡 不画我` 撤回。数据保存在 `{persona}/artifacts/gacha/`。
