# 群聊手帐（chat_analyzer）

把一段群聊做成一张**横版手帐**：左边一张封面（标题、群聊天气、今日一画、她的一句话、四个数字）贯穿整页，
右边三列等宽网格、同一行卡片等高，边线全部对齐；最后附上她自己写的日记。日报看今天，周报看这一周。

- 指令：`/ca daily`、`/ca weekly`、`/ca analyse [分钟]`
- 定时：每天 22:00 日报、每周日 21:30 周报（插件设置里可改，改了**即时生效**，不用重载）

## 手帐上有什么

| 版块 | 怎么算的 |
| --- | --- |
| 群聊天气 · 群温 | 开心词（含「哈哈」类笑声）和丧气词的比例定晴 / 多云 / 小雨 / 雷阵雨，又开心又热闹是彩虹，冷清是微风 / 静夜；群温按消息量的对数折成 °C（一天 30 条约 15°，千条约 35°） |
| 她说的一句话 | 她给这一期写的封面句，也是发图时那句话 |
| 今日一画 / 本周一画 | 一整页绘本式的场景：她按这一期的剧情章节写画面，提示词里再按时间顺序列出每段必须画进去的事和当天的天光；复用已存的形象图——她自己的 `assets/`，以及这一期说过话或被 @ 过、在 `bot_assets/` 里存了设定图的 AI 伙伴（参考图顺序和提示词一一对应）。真人群友画成看不清长相的 Q 版小人。没画成就贴一个大大的天气 |
| 小贴纸 | 消息数（比昨天 / 上周涨跌）、冒泡人数、最热十分钟、表情和图 |
| 今日剧情 | 一天的消息密度画成一条「时间河」，沉默超过 20 分钟就断成一段；最热的几段是河上的小旗，她给每段起标题、写一句经过，附参与者头像和这段的高频词 |
| 花朵时钟 | 24 片花瓣，越长那一小时越热闹，最热的那瓣戴皇冠 |
| 今日称号 | 话痨之星、气氛组组长（笑得最多）、破冰小能手（冷场后第一个开口）、接话王、人气王（被 @ 最多）、表情包仓库、夜猫子、早起鸟、好奇宝宝、长文作家、随手摄影师；每人最多一个，让更多人上榜 |
| 聊得来的两个人 | 两人两分钟内一来一回算 1，@ 对方算 2 |
| 笑点与复读 | 笑点：一句话之后两分钟内至少两个人笑出声；复读：同一句短话五分钟内被至少三个人发。图片、表情、戳一戳都不算 |
| 话题泡泡 | 无分词的 2–6 字 n-gram，去掉口水词、说过话和被 @ 到的人的名字（含「雀哥哥」这类昵称 + 称呼）和屏蔽词 |
| 冒泡排行 | 前几名的发言数 |
| 卡片底部的小统计 | 每张卡片底边压一条同色小统计，同一行对齐：剧情——成段聊天数、最长一段、最长的安静、接话中位数；花朵时钟——凌晨 / 上午 / 下午 / 晚上的分布、第一句和最后一句；称号——拿到称号的人数、平均一句几个字、表情包数；笑点——笑声次数与占比、最爱笑的人、笑声最多的钟点；CP——你来我往的次数、社交中心（和最多人聊过的人）、互相 @ 次数；排行——前三名的占比、人均条数、路过打招呼的人数；周报糖豆日历——最热的钟点、工作日 / 周末日均 |
| 她的今天 / 这周 | 日记旁边：她说了几句、接过几个人的话、最常接谁的话、她最活跃的钟点 |
| 她的日记 / 周记 | 她用平时说话的口吻写的一段；提到的群友（她写 `<@QQ号>`，或直接写出名字）显示成带头像的小名牌，剧情章节的经过也一样 |

周报另有：一周群聊天气（每天一个天气和群温，最热那天戴皇冠）、糖豆日历（7 × 24，豆子越大越热闹）、
群友星座（力导向小网，连线越亮聊得越多）、本周大事记（每天最热的一段，挑最热的四段）、
悄悄升温（比上周多出一倍的词）、全勤打卡和新面孔。

## 指令

| 指令 | 作用 |
| --- | --- |
| `/ca` | 用法和自动发送时间 |
| `/ca daily [昨天]`（也可写 `日报`、`每日`、`report daily`） | 今天 0 点到现在；凌晨六点前或写「昨天」给完整的昨天 |
| `/ca weekly [上周]`（也可写 `周报`、`每周`、`report weekly`） | 本周一到现在；周一中午前或写「上周」给完整的上周 |
| `/ca analyse [分钟]`（也可写 `analyze`、`群聊分析`、`聊天分析`） | 最近 N 分钟（10–10080，默认 1440），日报版式 |

只能在群里用；同一个群上一份还在画时会让你等一下。出图失败（没装 chromium）时退回文字版。

## 设置（WebUI → 插件设置）

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `daily_enabled` / `daily_time` | 开 / `22:00` | 自动日报；时间在凌晨六点前表示发前一天的 |
| `weekly_enabled` / `weekly_day` / `weekly_time` | 开 / `7` / `21:30` | 自动周报，`weekly_day` 1=周一 … 7=周日 |
| `min_messages` | 30 | 当天少于这么多条就不自动发日报，周报按 3 倍算 |
| `illustration` | 开 | 画「今日一画 / 本周一画」 |
| `art_per_day` | 3 | 每天最多画几张（所有群合计）；手动指令同一周期复用已画好的，定时那次会重画最新的 |
| `allowed_groups` | 空 | 允许的群号白名单，留空表示所有群 |
| `blocked_words` | 图片 / 表情等占位词 | 话题泡泡里不想看到的词；她自己的名字自动屏蔽 |

旧版的 `schedule`（`[{"time": "22:00"}]`）仍会被当作日报时间读取。

## 定时怎么工作

插件注册一个每分钟的 `timer.tick`，自己判断有没有到点：到点后两小时内都算数（重启、休眠错过了会补），
每个群每个周期只发一次，发没发记在插件数据 `sent:{day|week}:{群号}` 里，重启不会重发。
发送走框架的主动消息管线，图片先落到 `plugin_data/artifacts/chat_analyzer/`，只留最近 30 张。

## 数据与依赖

- 消息来源：引擎归档 `{work_path}/archive/{group_id}.jsonl`，按时间窗从文件尾部倒着读，读过窗口就停；
  归档不存在时退回 `basic_memory` 内存窗口。她自己的发言不进排行和称号。
- 文字：一次 `plugin_generate` 调用，输出 JSON（封面句、各段标题和经过、日记、插画画面）；
  解析失败时用程序写的事实句兜底，日记版块不出现。
- 插画：`ctx.engine.generate_image`（任务名 `image_generate`），画里不出现群友本人、文字或号码。
- 消息清洗：戳一戳（`戳了一下 …`）整条不算；引用块 `[引用消息 …][/引用消息]` 和合并转发块不算这条消息说的话；
  `[图片]`、`[表情]`、`[语音]` 等占位和 `@昵称(群昵称为…)` 都从正文里去掉，纯图片 / 表情消息只计入表情和图。
- 头像：`q1.qlogo.cn` 公开接口拿真实 QQ 头像，缓存三天在 `artifacts/chat_analyzer/avatars/`；拿不到画首字头像。
- 出图：playwright + chromium（`python -m playwright install chromium`，官方镜像已带）。
  字体内嵌站酷快乐体（框架自带）+ 系统黑体，不外链任何资源，不用 emoji 字体（图标都是内联 SVG）。

## 排错

| 现象 | 排查 |
| --- | --- |
| 回「这段时间群里还没有聊天记录」 | `data/personas/<人格>/archive/` 下有没有这个群的 jsonl，时间窗内有没有消息 |
| 只回了文字版 | 本机缺 chromium，日志里搜「群聊手帐出图失败」 |
| 没有今日一画 | `illustration` 是否开着、`art_per_day` 今天是否用完、AMKR 的 `image_generate` 任务是否可用 |
| 定时没发 | `daily_enabled` / `weekly_enabled`、时间格式、白名单、当天消息是否够 `min_messages` |
| 头像全是首字 | 服务器访问不到 `q1.qlogo.cn`，属预期降级 |
